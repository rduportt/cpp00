# CPP Module 00

> First steps in C++: namespaces, classes, streams.

## What's inside

- Namespaces, classes and member functions
- Standard input/output streams
- Initialization lists, static and const
- Exercises: Megaphone, PhoneBook, Account

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
